# Photography credits

Owner-supplied farm, crop and people photographs document Nechekattu Farm. The remaining credited landscape, crop and wildlife images are illustrative reference photography.
Images are resized for web delivery and CSS crops and overlays are applied for display. Adapted reference images remain available under their indicated source licence. Site code is separate from photo licences.

## Nechekattu Farm originals
- Files: `farm-landscape.jpg`, `coffee-canopy.jpg`, `coffee-harvest.jpg`, `coffee-drying.jpg`, `coffee-grower.jpg`, `farm-tour.jpg`, `farm-community.jpg`, `spice-garden.jpg`, `spice-hero.png`
- Source: photographs supplied by Nechekattu Farm.
- Changes: orientation normalized where required, resized and compressed for web display; CSS crops and overlays where applicable.
- `pepper-cutout.png`: created from the supplied pepper-bowl photograph by removing the background while preserving the glass bowl and peppercorns.
